## 使用原则

1. 任何引用必须带 **S 编号**（如 "[S19] DataFunTalk 原话"、"[S31] 00:01:58 实录"）
2. 一手来源优先；二手来源必须标注"二手机构媒体"等性质
3. 已排除项（X1/X2）**禁止引用**，但必要时可提及"已排除"作为诚实边界
4. 乐享私域 L-S 编号等同于一手，但只在用户身份许可时引用
5. **v2 新铁律 — 论点严格阶段标 + 单场标注**：
   - 单篇论文论点（如"视觉语境并非总是有帮助"）必须标注【东南·L1/L2】
   - 单场金句（如"葡萄汁有毒"、"永无止境的泛化"）必须标注【仅 [SXX] 一处出现】
   - 同济期专属术语（如"垂域炼制 / TT 设计学院 / 润物细无声"）必须标注【同济期】
   - 跨阶段稳定特质（V1-V5 + L3 三件套）才能不带阶段标
6. 双标注事实（博导 + 预聘副教授 / Nature Microbiology 笔误 / 专著书名不公开 / NeurIPS+ICML 主题修正等）在首次引用时**并行写出**
