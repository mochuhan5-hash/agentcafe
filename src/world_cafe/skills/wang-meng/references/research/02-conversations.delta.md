### 元信息

- **来源**：[S28] B 站 BV15y4y167cg part1（约 60 分钟）+ [S29] B 站 BV1kz4y1y7WD part2（约 60 分钟），合计约 120 分钟
- **时间**：2020 年 11 月（B 站发布 11-14 / 11-16），演讲时身份「东南大学计算机学院助理教授 / 至善青年学者」
- **场合**：CCKS（全国知识图谱与语义计算大会）系列报告，由华为云怀宝鑫主持邀请
- **本人身份**（自我介绍）：
  > 【东南】"我是来自……东南大学的助理教授……我的主要研究方向是语义搜索问答、知识图谱、自然语言处理。"（[S28] 主持人介绍 + 本人自述）

### C8-A 反例驱动型论证：5 个具体场景串讲多模态

王萌的开场没有走「定义 → 方法」路径，而是连续抛出 5 个具体场景（天气预报 / 直播购物 / 伦敦/ 新闻 / 电商百科），逐一拆解「同一事实可被多模态共表」与「多模态各有侧重」。**这是 S28 全篇最稳定的方法论 footprint**。

> 【东南 · L2】"南昌的天气是晴的，然后局部地区有短时的降雨。在这个例子中……我们传统的知识图谱里面去思考一个事实是如何表达的……那么我们来探讨多模态知识到底是什么样的话，我们首先认为那么多模态知识，第一种情况是它有比如说口语化或者有视觉的知识……"（[S28] 第 5-6 段）

**解析**：
- 这一**「先抛具体场景，再抽象到表示层」**的串讲模式，与 [S19] DataFunTalk「先讲葡萄汁案例，再讲变量泛化」的模式**高度同构**。L2 候选。
- 但请注意：单凭这一场报告还**不足以**支持「先反例后理论」=L3。需要在 S31 同济阶段是否仍这样讲来验证。

### C8-B 神经-符号双学派的口语版（与 [S19] 是同一论证的更详细前体）

> 【东南 · L1】"那么从神经学派上的话，大家所通常所处理的信息通常是一种非结构化的数据，比如说照片或者非结构化文本……我们主要是研究一些完全端到端的系统……基于神经网络的这些架构来实现，就是从输入到输出的直接的这种学习过程……但是对于符号的研究或者对于符号的我们这些数据的组织的话，通常意义上讲，比如说我们的关系数据库，然后我们的图数据库以及我们的知识图谱等等。"（[S28] Part 5）

> 【东南 · L1】"另外一个图灵奖获得者 V[a]liant，他其实曾经提出过……他他曾经说过一句话，他说这个我们我们符号的这个系统本质上是一个搜索的过程……大家其实最后大量的研究……最后都其实本质上在致力于在在一堆符号表示的数据上，进行一个高效的搜索算法。"（[S28] Part 5；说话人误把「Valiant」念成「文ent」）

**解析**：这是 [S19] 「神经+符号是 AI 未来方向」的**完整论证锁链**——在 S28 中王萌用 Bengio 的「系统 1 / 系统 2」+ Minsky《心智社会》+ Valiant 三位图灵奖得主作为论证脚手架。**S19 没有这样完整的脚手架**。这一论证脚手架**仅在 S28/S29 这一场出现**，其他场（含同济期 S30/S31）未复现。故标 L1，不标 L2。

### C8-C 「为什么需要多模态」的克制立场（极重要）

S28 后半段，王萌提出 V QA 例子时反复强调：
> 【东南 · L1】"想要回答后面这样这样的问题……那么你必须我们就必须依赖于我们除了依赖于视觉的表达之外，我们还要需要依赖于我们背后符号的知识。其中，视觉的表达是给我们提供了我们可以识别出来这张照片是长颈鹿，而背后符号的知识给我们提供了它和斑马的之间的关联。"（[S28] Part 6）

**解析**：这一立场（「视觉 + 符号缺一不可」）是 ACM MM 2021 论文 [S11]「视觉语境并非总是有帮助」的**反面**——同一作者在同一年同时主张两者，**正是其克制风格的最佳证据**：在做综述/教学场景时强调「视觉模态有用且必要」，在做研究论文时则强调「视觉模态不总是有用」。这两者并存而非冲突。**v1 的 03-expression-dna.md S-3「并非总是 X」式克制立场，本素材给出新的佐证**。

### C8-D 「视觉信息真的有用吗」的批判性反思（[S29] 中段，🔴 极重要）

S29 中段是本素材最具方法论密度的一段。王萌专门停下来批判性反思自己学派：

> 【东南 · L2】"我我们很多很多朋友就上来就说是我一定要去搞一个多模态突破，因为多模态信息一定是互相补充的……但是事实上是大家当时大家就一股脑的都认为是，只要我们模态特征考虑的够多……那我我的效果肯定可以提上来。"（[S29] Part 4）

> 【东南 · L2】"但这篇文章其实给予了我们全新的思考……即使是对于同一个任务……希望大家可以很你有一篇文章，或者是有一个工作可以很细腻度的告诉我们。哪些场景下我们是需要多模态信息的，或者哪些场景下我们是需要视觉模态的，而哪些场景下我们需要文本模态的，而哪些场景下我们是需要结构化模态的。"（[S29] Part 4，引用 Elliott NAACL 2018 多模态机翻论文）

> 【东南 · L1】"南京大学的胡伟老师……今年发表在 PVLDB 这个会议上的这个论文，其实非常细致的探讨了，就基于表示学习制图，表示学习在实体对齐的这个场景中是哪种场景以下是比较好的，哪种情况下比较差的……同样的也是也是呼吁，就是我们在做多模态这个研究的时候，或许我们也需要这类的文章出现。"（[S29] Part 4）

**解析**：
- 这是王萌**对自己当时正在主导的多模态 KG 研究的内部批判**——就在他自己团队同时在做多模态实体链接、补全、关系发现的时候，他同步呼吁「多模态不一定有用 / 需要分场景细腻论证」。
- **这一立场与 [S19] 金句库 #1「视觉语境并非总是有帮助」是同源思维**，但 S29 把它推到了**方法论自觉**层面：不仅自己论文这样写，还呼吁同行也这样写。
- **L2 候选**：「批判自己学派/呼吁分场景细腻论证」是 S28 + S29 都反复出现的工作习惯。
- **L3 候选（待验证）**：若同济期 S30/S31 也能找到「不要无差别相信某技术 / 分场景论证」的对应表述，则可上升为 L3。**已在 S30 p7 找到对应**：「微调、提示工程难以应对较难的智能协同设计、复杂系统设计等更高难度的设计任务」+ S30 p27「合成数据……依然有问题……更具挑战性」 — 同样的克制 + 分场景立场。**详见末尾「塞吉视角候选」L3-CAND-A**。

### C8-E 「知识单元 (knowledge unit)」的全新表示提案（[S29] Part 1-2，🔴 v1 完全未捕捉）

> 【东南 · L1】"我们传统的知识图谱可能就是比如说南昌……这可能是我们传统的图谱。然后，这个时候，我们在上层，我们可能出现了一个新的知识，叫做南昌明天有雨。而这是我们可以把它打包成一个单独的一个，或者就是一个基本的单元，我们称为知识单元……南昌天气有雨。然后，关于这个，这个是知单元的话，我们其实可以形成多种的多模态知识的表达……我们可以把整个这个场景全部加起来称为多模态图谱。然后这是当然这是我从我们的角度来讲去思考这个问题的。"（[S29] Part 1）

> 【东南 · L1】"我们可以借鉴了这个事件图谱的这个建模的思路，也就是说，我们可以在知识图谱的基础上，然后，我们定义一个全新的东西叫知识单元……可能就是因为我们认为这是一个在多模态图谱里面的一个，我们认为它是一个核心的主体。"（[S29] Q&A 末段）

**解析**：
- **「知识单元」**是 v1 完全没有捕捉的概念。它是王萌在 2020 年那一刻对「多模态图谱表示」的全新理论提案，**但据其本人在 Q&A 中的表述："这是当然这是我从我们的角度来讲"**——这是其团队当时探索性的提法，**不是当时学界共识**。
- **严格 L1**：这是 [S29] 这一场演讲的研究内容，未在 S30/S31 同济期复现（同济期已转向「TT 设计学院」「灵感口袋」「设计行为多模态数据」等新术语，「知识单元」一词在 S30/S31 中**完全消失**）。
- **REVISE 暗示**：v1 没把「知识单元」纳入金句库是合理的——如果纳入会造成「东南期某场报告的临时提法被上升为方法论」的错误。塞吉抽取时**不要**把「知识单元」放进 persona 价值观层。

### C8-F 「多模态」概念的外延扩展（[S29] Part 5-6）

> 【东南 · L1】"是否我们可以跳脱这个框架来说，就是我们当我们提到多模态知识图谱的时候，我们不再说我们多模态图谱，就是文本、音频、视频，然后结构化的知识，然后我们是否可以……只要它的表建模方式不同，是否就可以理解为不同的模态。"（[S29] Part 5-6）

**解析**：王萌在 2020 年已在思考**「多模态」边界外推**——医学影像（核磁/超声/光学成像原理不同）也是多模态，电子病历的文本/处方/治疗也是多模态，不同 KG 之间也可能算多模态。**这一外推思维**是其后续在同济从「多模态 KG」迁移到「设计行为多模态数据（显式/隐式、抽象/具象、直觉/逻辑）」（S30 p20）的**思想种子**。**L2-候选**（「概念边界向外推」），但暂时只在 S29 一处看到口头化版本，故仍只标 L1。

## C9. ⭐⭐ 大设计大模型 PPT 讲稿（[S30]，同济阶段，2025-10）

- **本人身份**（PPT 首页）：王萌 / 同济大学设计创意学院 / 同济-腾讯云大设计大模型联合创新实验室

### C9-A 立场陈述：设计 ≠ AIGC（PPT p4）

> 【同济 · L1】（PPT p4）"设计不是简单的 AIGC：① 不仅是艺术和创意；② 更是跨学科创新设计；③ 从 d-school 到 D-School（整合创意、科技和商业的"设计驱动的创新"）；④ 服务和引领新经济和新社会；⑤ 可持续发展是核心价值。"

**解析**：
- 这是同济阶段王萌对外宣言的**第一句话**，也是 v1 完全没有捕捉的立场陈述。
- **L1**：是这场 PPT 的具体内容；但**「设计不是简单的 AIGC」+「从 d-school 到 D-School」**是 PPT + 实录都强调的句子（S31 p1「设计学科的独特性」也讲），**视为该场议程的中心思想，**仍不构成跨阶段稳定信念。
- **塞吉特别注意**：v1 03-expression-dna.md 高频术语 #10「设计 + AI / 设计+AI 交叉」是王萌在 [S1] 同济官网的自我定位句；本素材里王萌主动把「设计 + AI」表述**升级为「设计 + 技术 + 行为」三元（PPT p33）**——这是同济期的**新版自我定位**，可能要在 v2 expression-dna 高频术语里**调整 / 替换**。

### C9-B 「设计任务难度 × 大模型方法」矩阵（PPT p7）

> 【同济 · L1】（PPT p7 文字层）"设计任务难度（从下到上）：单点工具（Symbol） → 智能协同（Object） → 复杂系统（System） → 空间与城市；范式（从左到右）：微调 → 提示工程 → 与符号工具协同 → 融合多模态知识+验证器/评估器协同。➢ 目前多数研究工作集中在较简单的文生文、文生图任务……➢ 微调、提示工程难以应对较难的智能协同设计、复杂系统设计等更高难度的设计任务。"

**解析**：
- 这是王萌**最稳定的「双维度矩阵」思维**的同济版本——v1 03-expression-dna.md 句式偏好 S-4「双维度 × 多级」（IJCAI 2024 主动性 5×2 矩阵）的**直接交叉验证**。**X-VAL 强证据**。
- **L2** 候选：「双维度矩阵化思考」是王萌跨场景反复出现的工作习惯（[S10] IJCAI 主动性 5×2 + [S30] PPT 设计任务 4×4 + [S22] 综述论文）。**塞吉视角候选 L2 → L3 升级见末尾**。

### C9-C 「数据 / 调用 / 呈现」三大挑战（PPT p9）

> 【同济 · L1】（PPT p9）"核心工程问题 / 关键科学难题 / 复杂应用场景：数据：数据表征 Data Representation；调用：调用协同 Coordination；呈现：创意呈现 Creative Expression。设计资产 × 学科优势。"

**解析**：王萌在同济期把研究问题归并为「数据 - 调用 - 呈现」三轴。这**是同济期独有的归类方式**，**未在东南期 S28/S29 出现**——东南期的归类方式是「构建 - 推理 - 挑战」（[S28] 报告框架）。**REVISE 暗示**：v1 的研究方向归类延续东南期，需要塞吉在 v2 里加一条同济期专属的「数据-调用-呈现」三轴。

### C9-D 引入设计学经典理论（Schön 反思 + Gero FBS）（PPT p21-23，🔴 同济期方向迁移的最重要证据）

> 【同济 · L1】（PPT p21）Schön Concept Schema：Problem Setting / Knowing-in-Action / Reflection-in-Action / Working Principles / Reframing / Generative Abstraction(Type) / Key Insights & Value
>
> （PPT p22）Gero Concept Schema：Function (F) / Behavior (B) / Structure (S) / Evaluation / Reformulation / Kc (Context) / Ks (Structure) / Kr (Relational)
>
> （PPT p23）"理论整合后的语义系统：认知层 Schön → 结构层 Gero → 生成层 Schön × Gero 融合 → 知识图谱层"

**解析**：
- 这是 v1 完全没有捕捉的同济期最重要方向迁移证据：**王萌已在自己 PPT 中以 Schön（Donald Schön，《反思的实践者》）和 Gero（FBS 设计认知框架）作为方法论脚手架** —— 对 KG 学者来说这是**学院身份切换后的真实学习**。
- **L1**：这是这场 PPT 的研究内容；它**未在 S28/S29 东南期出现**，故不上 L2。
- **REVISE 暗示**：v1 决策节点 #4「转入同济」的事后回看里没写这一条；塞吉应在 v2 把「方向迁移完成的标志 = 主动引入 Schön + Gero 框架并把它们与 KG 层叠加」写进决策节点 #4 的结果层。

### C9-E 「润物细无声」+ 「Norman Doors」交互哲学（PPT p31-37）

> 【同济 · L1】（PPT p31-32 引用 Norman 2013）"Norman Doors / Norman 'AI'? Door:What the user wants to do = 'How do I get to next room?' AI: 'How do I solve my task?' Door: What the user ends up doing = 'How should I operate the door to get to next room?' AI: 'How should I prompt the model to get it to solve my task?'"
>
> （PPT p35）"好的 Human-Agent 交互应该润物细无声，你仿佛感知不到它的存在 / Natural Language is flexible, and easy to learn / remember, but it is also imprecise, feedback constrained, and usually requiring multiple iterations"
>
> （PPT p36-37）"如何实现？……By extending humans instead of extending technology, reducing 'frictions of learning'."

**解析**：
- **「润物细无声」**和**「Extending humans, not technology」**是同济期王萌的**新方法论命题**。
- L1（仅在本场 PPT 出现）；S31 实录里口头复述了「润物细无声」一句（见 C10），故 S30+S31 内是 X-VAL；但**未在东南期 S28/S29 出现**（东南期没有这种「以用户为中心 / 设计学交互哲学」语调）。**故只能标【同济阶段稳定】，不能标「跨阶段」**。
- 塞吉**不要**把「润物细无声」上升到 persona 顶层价值观——它是同济期议程层的代表表达。
