# 05 · 领域背景与研究/职业决策节点

> 范围：王萌**学术轨迹中 5 个关键决策节点**——决策时间 + 触发因素 + 选择 + 结果。
> 风格：以"决策框架（Decision Frame）"分析模式呈现，每节点附"事后回看"小结。

## 决策节点 #1：2018 年博士毕业 → 选择**学术界**（东南大学）

### 时间
2018 年（西安交通大学博士毕业；含澳大利亚昆士兰大学联合培养经历）

### 触发因素
- 博士在读期间已在 ISWC / ICBK 等专门会议有产出（[S20]/[S21] 一手）；
- 中澳联培经历（[S1] 一手）打开国际视野；
- 当年（2018）国内 KG 研究正处于**学术热度上升期**（OpenKG 2015 启动后正值生态爆发）；
- 东南大学计算机学院在 KG 方向有团队基础。

### 选择
- 加入**东南大学计算机科学与工程学院**任**助理教授**；
- 早期获**"至善青年学者"**称号（[S17] 复旦讲座海报对其身份的引用 — 二手机构介绍 / [S1] 一手）。

### 结果（事后回看）
- 入职当年（2018）即收获 **ISWC 2018 最佳论文提名**（[S20]）+ **ICBK 2018 最佳论文**（[S21]）双奖项 — 学术起点的高位锚点；
- 进入王昊奋团队的合作链（综述论文 [S22] 第一作者，王昊奋第二作者）；
- 为后续转入同济（合作者王昊奋已先迁同济）埋下机构衔接线。

### 决策画像
- **风险偏好**：低（选择有团队基础的传统计算机学院 vs 直接闯设计学院）；
- **方向锚点**：纯算法 KG（嵌入 + SPARQL）；
- **可信度**：一手（教育/任职事实） / 推断（决策动机层）

## 决策节点 #2：2018—2020 → 聚焦"**KG 嵌入 + SPARQL 查询优化**"

### 时间
2018—2020（东南大学早期 2 年）

### 触发因素
- 博士期工作积累指向 KG 嵌入这一**当时最热门**的子方向（TransE 系列方法 2013 后持续发酵）；
- 学界开始关注 KG 嵌入的**实用化**——不仅做 link prediction，也用于查询优化、问答；
- ISWC/ICBK 评审反馈（最佳论文提名/正奖）**正向强化**该方向。

### 选择
- 锁定 **"嵌入 × 查询"** 交叉路径：
  - **ISWC 2018**：用 RDF 嵌入解决 SPARQL **空答案**问题（[S20]）；
  - **ICBK 2018**：用 KG 嵌入构建图结构化查询（NL → Graph Query）（[S21]）；
- 而**没有**选当时更"热闹"的纯 link prediction / KG completion 跑分方向。

### 结果（事后回看）
- 双最佳论文（提名 + 正奖）——证明该路径的差异化价值；
- 形成**"嵌入是工具，查询是问题"**的方法论坐标；
- 该坐标在 2024 年同济阶段以"VQFT 可视化查询"（VLDB 2024）和"个人 KG QA"（SIGIR 2024）形式延续——**核心方法论稳定性极高**。

### 决策画像
- **差异化策略**：选边缘问题（空答案、NL→Query）而非主流跑分；
- **方法论遗产**：贯穿至今的"嵌入 + 用户查询场景"双锚结构。

## 决策节点 #3：2020—2022 → 向"**多模态知识图谱**"扩展，提出"**选择性融合**"

### 时间
2020—2022（东南大学晚期）

### 触发因素
- 2020 年起 CLIP / 多模态预训练模型崛起，**多模态学习成为 AI 主流议题**；
- KG 社区对纯结构化 KG 的天花板有共识，多模态 KG 成为新增长点；
- 2020 年复旦讲座 [S17] 主题已是"多模态知识图谱构建研究与挑战"——王萌**早于学界主流**至少半年开始介入。

### 选择
- **不做"加图就提升"的乐观假设**，反向提出 **"视觉语境并非总是有帮助"**（ACM MM 2021，[S11]/[S19]）；
- 引入**门控/选择性融合**机制；
- 用 **"阿司匹林：药盒 vs 分子结构图"** 的具体反例支撑论证（[S19]）。

### 结果（事后回看）
- ACM MM 2021（CCF-A）发表，**为同领域论文提供反思参照系**；
- 这一"反直觉式陈述"成为王萌**最具辨识度的学术主张**（金句库 #1）；
- 延伸至 IJCAI 2024 的"五级主动性"框架——**同样的克制立场**（不是"越主动越好"，而是"分级讨论"）。

### 决策画像
- **学术风格**：**克制 + 边界条件意识**；
- **研究品味**：选反直觉问题，不追大跑分热度；
- **可信度**：一手（论文 + 演讲复述）

## 决策节点 #4：约 2022—2023 → **从东南大学转入同济大学设计创意学院**

### 时间
约 2022—2023（具体月份未公开 — 诚实边界已记）

### 触发因素
- 合作者**王昊奋**已先期转入同济，KCL 实验室在同济落地（[S14]/[S15] 一手）；
- 同济正在筹建"**大设计**"战略（[S7] 同济新闻），需要 AI 方向的核心学术力量；
- 同济-腾讯产学研合作启动，需要 KG / LLM 学术对接人；
- 王萌个人已在多模态 KG 完成方向定型，**寻求更大的应用落地场域**（设计 vs 纯计算机）。

### 选择
- 接受**同济大学设计创意学院预聘副教授**职位（[S1] 一手）；
- 研究方向定位句**正式更新为"面向'设计+AI'交叉领域"**（[S1] 本人撰写，金句库 #8）；
- 保留 KCL 实验室合作（与王昊奋持续合著）。

### 结果（事后回看）
- 完成从"计算机学院 / 纯算法"到"设计学院 / 应用导向"的**学院身份切换**——这在国内学者中相对少见；
- 同济阶段产出向**应用场景**集中（车载 IJCAI、VLDB 可视化查询、SIGIR 个人 KG QA、设计大模型）；
- 2026 年腾讯峰会确认**博导身份**（[L-S1]），完成正高级身份起步。

### 决策画像
- **跨界跳跃**：计算机 → 设计学院（非典型路径）；
- **机构嵌套策略**：通过 KCL 实验室保留计算机学术圈 + 通过设计创意学院开辟新场景；
- **可信度**：一手（任职事实）/ 推断（决策动机层）

## 决策节点 #5：2024—至今 → **拥抱大模型时代**，主导知识增强 LLM 与设计大模型方向

### 时间
2024—2026（持续中）

### 触发因素
- ChatGPT（2022.11）/ GPT-4（2023.3）后，LLM 成为 AI 主流；
- 王萌 2021 DataFunTalk 已锚定"**神经 + 符号**"路线（[S19] 金句库 #6）—— LLM 时代正是该路线的**工程化窗口**；
- 同济-腾讯**大设计大模型**项目启动（[S7] 一手机构媒体 / [L-S3] 操作手册一手）；
- 国家自然科学基金、上海市教委重点等项目密集支持（[S1] 一手陈述）。

### 选择
- 主导/参与**知识增强 LLM**方向（IJCAI 2024 / SIGIR 2024 / VLDB 2024 / NeurIPS 2024 / ICML 2024 — 当年同时命中 5 顶会，[S1] 题录）；
- 提出**五级主动性框架 + Rewrite/ReAct/Reflect**（IJCAI 2024，[S10]）作为知识增强 LLM 在交互场景的代表性工作；
- 深度参与**同济-腾讯产学研合作**（[L-S3] 知识引擎手册 / [S9] 腾讯新闻）；
- 2026 年作为**博导嘉宾**参与腾讯上海峰会智慧教育圆桌（[L-S1]）。

### 结果（事后回看，截至 2026.05）
- 同济阶段第二个 3 年完成**学术等级跃迁**：副教授 → 博导（峰会确认）；
- 学术坐标从"KG 学者"扩展为"**KG × LLM × 设计**"三轴学者；
- 产业生态完成"腾讯云大模型知识引擎"等具体落地（[L-S3]）。

### 决策画像
- **路线一贯性**：2021 锚定的"神经 + 符号"在 2024 LLM 时代得到验证；
- **生态绑定**：深度绑定腾讯产学研生态，是其同济阶段的**结构性优势**；
- **可信度**：一手（论文 + 项目）+ 二手（机构媒体）

## 五节点的纵向方法论 Trace

```
2018 ── KG 嵌入 + SPARQL（差异化路径，最佳论文双奖）
            │
2020 ── 多模态 KG（"选择性融合"反直觉立场）
            │
2021 ── DataFunTalk："神经 + 符号"路线锁定 ★
            │
2022 ── 转同济：研究方向迁移到"设计 + AI"
            │
2024 ── LLM 时代："Rewrite + ReAct + Reflect"，五级主动性
            │
2026 ── 博导确认 + 同济-腾讯生态深度绑定
```

**纵贯主线**：**变量的力量 → 选择性融合 → 神经+符号 → 知识增强 LLM** —— 不同阶段表述不同，但内在逻辑高度自洽，**没有方向性反复**。
