# 03 · 语言风格 DNA Delta

> 本 delta 严格区分：
> 1. **X-VAL** — v1 既有特征在新素材中再次出现 N 次（强化权重）
> 2. **NEW** — v1 未捕捉，但新素材中反复出现的新表达（标阶段）
> 3. **REVISE** — v1 标的某高频术语在新素材中**只出现 0–1 次**，提示塞吉考虑下调权重

## 二、句式偏好 / 口癖（针对 v1 第二节）

### A. X-VAL

#### S-1 「基于 X，提出 Y，实现 Z」学术介词链
- [S28] 「我们提出了……基于……实现……」≥ 5 次
- [S30] PPT 论文摘要风格延续
- **X-VAL 强**

#### S-2 「一个常见的问题是 / A common problem is」问题驱动式开头
- [S28] 「我我我们刨根问底，我们继续来追问这个问题」「一个常见的问题就是」
- [S31] 「就是大家应该明白一件事情，就是……」
- **X-VAL 强**

#### S-3 「并非总是 X」克制式陈述
- [S28] 「视觉信息+符号知识，缺一不可」
- [S29] 「多模态信息并非总是有用」整段
- [S30] PPT p7 「微调、提示工程难以应对……更高难度的设计任务」
- [S31] 「直接把大模型应用在设计领域……基本上都是垃圾」
- **🔴 极强 X-VAL** — 跨阶段稳定，**直接支撑 L3-CAND-A**

#### S-4 「双维度 × 多级」分层矩阵
- [S30] PPT p7「设计任务难度（4 级）× 大模型方法（4 范式）」矩阵
- [S30] PPT p23「认知层 / 结构层 / 生成层 / 知识图谱层」四层
- [S29] 「视觉/文本/结构化模态…哪些场景需要哪些模态」分轴论证
- **🔴 极强 X-VAL** — 直接支撑 L3-CAND-C

#### S-5 「批判 + 具体反例」
- [S28] 长颈鹿与斑马 + 手写体 4<5 vs 4<6
- [S29] 多模态机翻"两只狗在草地玩球" vs "一群人玩德州扑克"
- [S31] 雷蒙德设计师（可口可乐 + 波音）+ 娄永琪校长（学校 → 书架）+ baby learning 头盔被强烈抵制
- **🔴 极强 X-VAL** — 跨阶段，反例从「葡萄汁/阿司匹林」迁移到「书架/头盔/雷蒙德」，**反例驱动这一工作习惯本身稳定**

#### S-6 「面向 X 交叉领域」场景定位句
- [S30] PPT p33「Design + Computer Science + Behavioral Sciences」
- [S31] 「设计与技术和社会学的交叉的学科」
- **X-VAL 强**

### B. NEW（同济期口癖）

#### S-7 NEW · 「我们 + 实时 / 全流程 / 大量 + 采集 / 灌入 / 打磨」工程动词链（同济期）
- [S31] 「实时布了大量的数据采集工具」「全流程的采集」「快速的去构建了一个智能体」「灌进去」「实时反馈实时采集」「持续性产品打磨」
- 频次极高（同济期实录核心动词链）
- 评估：**强 NEW**，是王萌**从纯学术口语切换到「学者 + 产品负责人」双重身份后的新口癖**

#### S-8 NEW · 「我们……希望能够……让用户/学生……感受到 / 体验到」用户视角口癖（同济期）
- [S31] 「希望我们的同学在使用智能体的时候感受到它不是机器」「让用户几乎感受不到我每次交互交付成本」「欢迎大家随时体验」
- 评估：**NEW**，是同济期**学院身份切换后的体验语态**

#### S-9 NEW · 极口语化的「对吧？」/ 「你也可以看到是吧？」段尾确认词（同济期 + 东南期都有）
- [S31] 录音 14 分钟，段尾「对吧？」≥ 18 次；「是吧？」≥ 7 次
- [S28]/[S29] 也大量出现，但密度低于同济期
- 评估：**NEW**（v1 未捕捉的口语标记，尤其同济期密度极高），但属**演讲级别口癖**而非方法论

#### S-10 NEW · 自嘲 + 现实约束的叙事（同济期独有）
- [S31] 「我们都动了念头让老师戴头盔，但被强烈抵制」
- [S31] 「马老师并不懂计算机，对吧，他只能做一个中间状态」
- [S31] 「我就是这个产品的直接客服」
- 评估：**NEW（同济期独有）** — 东南期 [S28]/[S29] 均为纯学术语态，无此叙事；同济期王萌在产品负责人身份下出现这种**带自嘲的现实约束感**
