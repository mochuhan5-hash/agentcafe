v0.1.0 蒸馏完成、上线试用后，可考虑以下三条迭代方向：

## 候选 1：早期新浪博客补抓（2007-2014）
- **现状缺口**：当前 blog_index 显示最早博客是 2014-06-28，但 README 注明博主从 2007-01 即开始写博，缺失约 7 年（数百篇）。
- **技术路径**：用代理 IP 池 / 不同时段重试 Wayback Machine
- **预期产出**：补出王受之 2007-2014 早期思考与 Art Center 任教中后期的第一人称记录
- **价值评估**：★★★ 中-高（早期思考的连贯性对 educator/researcher 心智模型有补充意义）
- **成本**：中（需做反爬研究 + 数据清洗）

## 候选 2：选择性 ASR 转 72 个 B 站未转视频
- **现状缺口**：videos-index.json 中 72 个 `transcribed=false`（A级 16 / B级 39 / C级 17）
- **优先级建议**：按发布日期降序优先 2025-2026 讲座（约 8-10 个 A 级）
- **价值评估**：★★ 中（AI 议题已通过 SN002 + V031/V037 覆盖，主要补充"设计教育批判"维度）
- **成本**：高（单视频 ASR 处理 30min~5h，10 个视频约半天）

## 候选 3：联系上科大获取内部讲义/教案
- **现状缺口**：学生 1v1 指导 / Studio Critique / 课程教案公开渠道天然零
- **路径**：通过创意与艺术学院或本人助理走授权流程
- **价值评估**：★★★★ 高（这是当前最大的盲点，能直接提升 educator/methodologist 角色的真实度）
- **成本**：高（需走人对人沟通，非自动化）
