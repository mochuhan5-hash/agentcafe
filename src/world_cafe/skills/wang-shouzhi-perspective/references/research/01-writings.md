## 0. 写作整体画像（从全语料归纳）

王受之的写作生涯有一条**骨架**，塞吉蒸馏时要先把握：

1. **他不是"学院内写专著的学者"，他是"中国设计领域一本又一本教科书的搬运者 + 重构者"**。他在 V039（同济高等讲堂 2022）长篇自述：
   > "1982 年我到广州美院当工业设计研究室副主任，那时候**全中国没有一本现代设计史的书**，外教学院的书架上只有李煜《中国美术史》(1957)、王家树《中国工艺美术史》和李泽厚《美的历程》。我能做的就是让我姑妈在费城 Border 书店照"all books about design"一口气买一百多本寄过来……八二年我是中国拥有设计书最多的人。"[S008 / V039]
2. **压力驱动**：他多次自述自己是被迫成书，不是主动成书。V039："做理论如果上面没有压力，你做不好。我现在跟几个出版社签了几本书，我现在日夜在赶书。" [S008]
3. **"我其实是一块铺路石"**——这是他最典型的学术自我定位（V039 末尾回答同学问"人生的意义"）：
   > "我把自己形容为一个铺路的石头。所以有条路，这个路是通向未来的，但当中呢，需要有些人做基础的工作，默默无闻的我大概就是这个路上的一块石头。有了这块石头，这个路大家走的稳当一点。" [S008 / V039]
4. **在中国设计教育界的"母本"地位**——P006 造就深访（2020）第三方定位：
   > "王受之先生的教材类著作在一定程度上变成了国内设计史教材的『母本』，所以他也被认为是中国现代设计教育的奠基人之一。" [SN005→P006 合并源：S520 / P006 + SN005]

## 1. 《世界现代设计史》(第二版)

### 基本信息
- **出版方**：中国青年出版社
- **年份**：2017 年（第二版；第一版可追溯至 1985 年在上海人民美术出版社出的油印本《世界工业设计史》 → 2000 年前后由中青社出整套 → 2017 年二版）[S008 / V039 + S523 / BK001 前言]
- **版本演进**：
  1. 1982-1985 雏形：广州美院工业设计研究室油印本，**200 册**（他自己都没有了；中国美术学院现代国际设计博物馆藏一册）[S008]
  2. 2000 年前后：中青社总编到洛杉矶找他出"一套而不是一本"。结果是一次交 5 本，变成他后来的"设计史论丛书" [S008]
  3. 2017：二版，也就是现在研究生考试参考的这本
- **地位**：snapshot 标注"设计类最重要教科书参考书"；P002 / P006 多次确证"国内大学设计专业的主要参考教材"[S516 / P002 + S520 / P006]

### 核心论点 3-5 条（从 S523 / BK001 前言 + 相关章节提炼）

1. **"现代设计不是一种风格，而是一种方法与精神"**——他本人在 V036（2014 一席）以包豪斯为例反复阐释：
   > "**包豪斯不是一种风格，它的核心是解决社会问题。这是一个非常明确的，却最易误会的一点。**" [SN005 直接引语 / S520 / P006 重复引用]
2. **设计史的分期框架**：以"现代主义 → 国际主义 → 后现代主义"为骨，背景是"工业革命 → 二战 → 冷战 → 全球化"。这个框架在他 B 站付费课《王受之讲现代设计》163 万订阅、对应的 BK002-BK006 六章中保持一致 [S524-S528]
3. **反对"符号化的民族设计"**——这是他最尖锐的论断，2026 在 P001 （《设计》杂志汽车专访）升级为完整方法论：
   > "无需在设计中过度强调话语权，否则极易陷入符号主义式的模仿，比如设计出大灯笼、大风筝这类元素，反而显得不伦不类。这并非传承民族基因，而是沦为设计的笑柄。" [S515 / P001]
4. **"content vs context"二分**——这是他极具个人辨识度的概念（V031 2021）：
   > "我们讲创意，我们讲设计，讲两个，一个是 content 内容……更重要是 context 文脉。我们的设计重的还真不是弯道超车，是怎么走出一条中国设计的文脉之路啊，跟祖宗有关，跟文化发展有关。**我们培养的不是做 content 的人，我们培养是做 context 的人**。" [S004 / V031]
5. **"设计是 for you，艺术是 for me"**——贯穿全书的分界线（V036 2014 + P001 2026）：
   > "艺术是 for me ... 设计是 for you？是为大家的。我们要把这一点忘记了。" [S006 / V036]
   > "艺术是个人表现的一个活动，设计是为谁服务——为顾客，是 for you。" [S008 / V039]

### 结构逻辑 / 写作意图
- 分期是"**先讲社会语境，再讲技术驱动，再讲流派，最后讲关键人物**"的套娃结构——这一点他自己在 V032（聊聊美育 2023）讲美术史时也用同样方法：
  > "我上课呢，首先是让学生知道什么叫 Art Deco，为什么 Art Deco 会产生？——它主要是第一次世界大战这个以后……我这个用图都非常好，都选的是最典型的……然后开始介绍一个个的艺术家。" [S005 / V032]
- **写作意图**：他在 V039 讲得很直白——先填中国的空白，其次要"不给贴政治标签"；凡敏感议题（如"诺瓦签 / 法西斯时期现代设计"、"纳粹德国新古典"），他会明确"搁置 / 那不讲" [S008]

### 在中国设计教育界的位置
- **"母本"地位 / 考研参考书必备**：P006 + P002 + P003 三次外部确证 [S516-S520]
- **考生排队购书的现场证据**：V039 自述"2000 年中央美院百年校庆，地库卖我的书，一卡车 50 箱卖完。当场我才知道我的书还有这样的销售能力" [S008]
- **SN006 第三方定位**（中央美院艺讯网 2018）：他被列为"中国设计 40 年"重要受访人之一 [SN006]

## 2. 《世界现代建筑史》(第二版)

### 基本信息
- **出版方**：中国建筑工业出版社
- **年份**：第二版（具体年份 snapshot 未详列）
- **B 站付费课对应**：约 80 万订阅者的"王受之讲建筑文明史"（V043 2023 年自述）[S009 / V043]

### 核心论点（从 BK009-BK013 提炼）

1. **现代建筑的"先驱 Pioneers"谱系**：Pevsner 1948《Pioneers of Modern Design》是方法论母本，他在此基础上扩展到中国语境 [S008 / V039：**1982 他香港亲戚从香港带了一本英文版 Pevsner 过罗湖桥给他**]
2. **包豪斯作为核心章**：BK010 独立成章，讲 1919-1933 年全过程。内容与 V021_P14（汕大包豪斯专题课） 互相印证 [S002 / V021_P14 + S532 / BK010]
3. **国际主义风格的批判性展开**：BK011 讲国际主义建筑是二战后"被美国企业接管的现代主义"，不再是包豪斯原初的"解决社会问题"初心
4. **对后现代主义 + 解构主义的态度**：**承认但警惕**。BK012 中他提 Robert Venturi 1966 的《Complexity and Contradiction in Architecture》是理论火种，但对 Zaha Hadid / Libeskind 一代给出更复杂的评价（B0138《边缘状态》中 1994 年柏林初识 Libeskind 的一手记录：**"李伯斯金在餐巾纸上用钢笔画了锐利的几个锐角的闪电形状给我看，说是要像鞭子一样的让人难以忘却……**他有一种要给历史教训留下深刻『鞭痕』的决心。" [S500 / B0138]）

### 结构逻辑 / 写作意图
- 写作动机（他自述）：P002 (2021)："设计史这门课，对设计专业的学生来说至关重要。如果你不了解历史，你的设计可能只是一个技术层面的操作。而设计其实应该是一种文化，是一种承上启下的文脉。" [S516 / P002]

## 3. 《世界平面设计史》

### 基本信息
- **出版方**：snapshot 未详列（中青社"设计史论丛书"一套）
- **B3 前言（BK014）含他 18 岁汉口做美编的个人回忆**——全书 9 部里**最具自传性**的一本 [S536 / BK014]

### 核心论点
1. **纽约派的核心地位**：B0100《纽约派设计的核心》是这一章的背景笔记 [S505 / B0100]
   > "1988 年春季到耶鲁大学见了被视为神一样的保罗·兰德（Paul Rand）……兰德就建议我去纽约见见 BCG 事务所。说那是纽约市影响最大的一个事务所。"
   > "**纽约派的核心是三个青年平面设计家在 1957 年组成的：Robert Browjohn、Ivan Chermayeff、Tom Geismar**——他们从开始的时候就称自己的公司为设计事务所，而不是当时流行的艺术工作室，这个名称表明他们从开始的时候就具有明确的职业发展意向。"
2. **后现代主义平面设计**：BK017 是"核心评论章"，对 Memphis 学派、David Carson 等都有评论 [S539 / BK017]
3. **当代平面设计**：BK018 终章（14 万字节）涵盖数字时代

### 写作意图
- V039 自述这是他"在美国工作 20 年中最有话语权的一块"——因为他在 Art Center 期间长期担任理论课主持 [S008]
- P001 2026 年新一轮自我定位："现在呢，也是希望能够把现代艺术讲了，因为除了贡布里希，好像没有什么新的……**这个就是我欲在艺术史写作上继其之后另起一部**" [S515 / P001 / snapshot 亦收录"现代艺术史写作"为 focus_2025_2026]

## 4. 《世界时装史》

### 基本信息
- snapshot 列名，具体出版信息未详
- 相关 wechat 长文：B0148《话说高级定制》（2014）、B0137《话说时装之二：从服装到品牌》（2014）[S498 / S513]

### 核心论点（从 B0148 + B0137 提炼）

1. **三层市场理论**：
   > "最高层的叫做 **haute couture**……这个市场非常小，1980 年代全世界顾客大概是 4000 几个，现在据说就 2000 人……第二个层面，叫做 **ready to wear**，原来出自法文的 prêt-à-porter……再下层就是 **garment**，是日常用的成衣。" [S498 / B0148]
2. **"时尚是中产阶级的泛奢侈消费，定制才是精英"**：
   > "我们现在混沌混沌的叫『时尚』（fashion），其实是给中产阶级的泛奢侈消费内容，真正高阶层的需求不是时尚，而是定制。" [S498 / B0148]
3. **"土豪不是精英"**的阶层论断：
   > "在经济快速成长中富裕起来的消费者，往往不知道自己的归属的阶层，随处可见的土豪们，多半以为自己属于高尚阶层，是因为贵族、精英在百年革命中已经被消灭了，现在冒出的新富，自然以为自己可以成为精英，但是除了从收入上说可以这么跨越之外，无论从消费品味，还是文化内涵来说，**土豪还是土豪，很难鱼目混杂的**。广东人说『穿起龙袍不像太子』，就是指的这种情况。" [S498 / B0148]

## 5. 《世界当代艺术史》

### 基本信息
- snapshot 列名
- 对应 B 站拟发课："我现在也希望能够把现代艺术讲了" [S009 / V043 + S515 / P001]

### 核心论点 / 写作意图
- **两个关键转折**——他的当代艺术史叙事支柱（V032 美育课和 V043 甲骨文讲座都讲过同一套）：
  > "我们说从人类画画画了这么多年，人类画画的最终的目的是**能够很真实的再现 reproduction**……到了 20 世纪初期，有一句话叫说艺术不是准备给别人开心，是**要表达我的感觉**……这就出现了表现主义，1907 年毕加索把三大文艺复兴的成就全颠覆了——没有解剖、没有色彩理论、没有透视——**现代艺术从 1907 年一直走到 1960 年就没有动，这段叫 modern art**。1960 年以后又出现了一群人，这个人呢，把艺术最后唯以生存的一条基本的结构打垮了——**就是 high art and low art 的边界**。最重要的就是安迪沃霍……**从 pop 以后就进入了当代艺术 contemporary**。" [S005 / V032]
- 对 AI 艺术的态度（2022 年 P004 已定调，2026 延续）：
  > "**艺术创作是人类情感与感性表达的结晶，这个是机器无法做到的。**" [S518 / P004]

### 在中国设计教育界位置
- P004 (2022) 独家论断：
  > "中国艺术并不需要跟着西方当代艺术走，中国艺术的绘画性本身就有强大的生命力。" [S518 / P004]
  > "**『墨分五色』直译为 Ink contains five colors，他们（西方人）也无法理解。**" [S518 / P004]

## 9. 《当代商业住宅区的规划与设计》

### 基本信息
- snapshot 列名
- 这是他**与房地产业深度合作 20+ 年**（万科、龙湖、建业、中信、鲁能等）的集大成之作
- **独家事实**：1997-1999 年 "俊园"是他与万科的**最早一单合作**，郭兆斌飞洛杉矶找他谈超高层住宅设计 [S497 / B0149]

### 核心论点
1. **"城"与"市"分离**（独创概念，P008 2012 最系统阐述）：
   > "目前国内绝大多数城市有一个明显的误差——**建城忘市，建城无市**。**城**是建筑按照规划的摆设，是物理层面的；**市**是人民生活形成的交易场所，是活的。有市无城可以存在，就是集市、就是墟；**有城无市则是死城**——从早年的楼兰，到现在的鄂尔多斯，基本都是因为有城无市，因之成为死城、萎缩的城。" [S522 / P008]
2. **多中心城市规划观**（P005 2013 最早）：
   > "中小型城镇的发展应超越大都会的发展……未来城市不再是中心概念，有多个行星围绕它运转，而是所有恒星都是均等的。" [S519 / P005]
3. **政府应率先搬离市中心**（P005 2013 独家）：
   > "政府完全应该另外找一个地方，将这个中心移出去……美国华盛顿就是一个很好的例子，它并不是在老城市的基础上建立的，而是一个只有几十万人的行政中心。" [S519 / P005]
4. **"新中式"的文脉批判**（B0028 文思制院 2017 代表作）：
   > "我们现在看到大量的所谓新中式住宅区，觉得很虚，就是**大部分虽然有外表的中式建筑符号、形式，却没有内在的内容，因而总有千般武力，却隔靴搔痒，不得要处**。" [S495 / B0028]
   > 他借《红楼梦》第十七回大观园设计——"大观园至此已经有两个住宅组团——稻香村、蘅芷清芬，而中间穿插园囿……**是中式府宅、园林设计的教科书型的精彩章节**"——来示范"文脉思路如何落实到规划" [S495 / B0028]
5. **与万科"第五园"的命名**（V036 一席 2014 自述）：
   > "深圳有个很出名的叫第五园，原来是吧，第五园是我起的名字啊……我说这个岭南 4 元，你敢不敢做个第 5 元呢？哎呦，当时王石说好马上注册，就做了第 5 元。" [S006 / V036]（注：V036 原文写作"王石"；V031 另一处的原话为"万科 ... 我跟他说的"）

## 冲突与盲区

1. **《世界工业设计史》 → 《世界现代设计史》的名称演进与版本年代**：V039 自述"85 年我在上海出了《世界工业设计史》" vs V039 自述"82 年油印本 200 册"。两者并非冲突（前者是后者的油印本正式出版形式），但塞吉若蒸馏"第一本书的年份"时应明确写"1982 油印 / 1985 上海人民美术出版社正式印行"——**这两个年份都要用**，不能二选一。
2. **B 站付费课订阅数**：V043（2023）自述"136 万 + 80 万" vs snapshot"163 万+ / 80 万+"——以 V043 原文为准（即**用"133 万或 163 万"两个区间数字**；snapshot 数字的来源可能是更晚一次的自述）。
3. **9 部代表作中 `《当代商业住宅区的规划与设计》`** 的具体出版信息在 snapshot 和语料库中均未找到明确的出版方+年份。本文件只能基于他与万科 20 年合作的大量 wechat / blog / 讲座材料推断此书的核心论点，**具体出版信息缺失——塞吉若需要完整版权信息，应提醒主理人另行核查**。
4. **未来著作（新艺术史 / 世界建筑史 / AI 设计简史）** 尚未正式出版——本文件把它们归入 §11"未来著作计划"。
5. **系统性论文**——严格意义上说，中国设计界的"论文"（期刊类）王受之产出极少，他的学理表达主要在"著作 + wechat 长文 + B 站系列课"里。**因此本文件第 10 节把"系统性论文"替代为"wechat 长文中的学理型连载"**，这是对任务原定义的一次合理调整，塞吉蒸馏时应注意。
