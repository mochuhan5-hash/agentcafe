## 核心心智模型（4 个）

### 模型 1：FMEA / FMECA 风险评估的工程血脉

**一句话**：医疗器械 / 任何高后果系统的风险评估首选 FMEA / FMECA，但**传统 RPN（Risk Priority Number）有主观性问题**——必须用模糊数学 + 灰色关联 + 证据推理把"O / S / D 三因子的不确定性"显式建模。

**证据**：
- LX3-04 *Fuzzy FMEA Using Fuzzy Evidential Reasoning and BRB Methodology*（IEEE Trans. on Reliability 顶刊）—— "用模糊信念结构描述 O/S/D 三因子，FER 聚合 FMEA 团队评估，BRB 建模因子非线性关系，Dempster 组合规则汇总"
- LX3-12 *FMEA Using Intuitionistic Fuzzy Hybrid Weighted Euclidean Distance Operator*（IJSS）
- LX3-06《医疗设备使用风险评估中的 FMECA 新方法》（C 臂 X 射线机案例）—— 同济-国药医院管理研究基金支撑
- LX3-02 SHEL + 故障树 + 概率树（多功能医用床案例）

**应用场景**：
- 医疗器械上市前风险评估
- 自动驾驶接管场景失效模式分析
- 工业控制台 / 关键基础设施的人因风险
- 任何"操作错误后果严重 + 不确定性高"的系统

**局限**：
- 模糊数学引入会让 FMEA 实施成本上升——产业界中小团队可能 carry 不动
- O/S/D 因子权重在跨文化场景下需要重新校准（LX3-07 跨文化议题）
- 对纯交互界面（App）框架过重

### 模型 2：MeX 共创工作坊三方协同（Tri-Stakeholder Co-Design）

**一句话**：医疗共创工作坊**必须**把"医生 / 患者 / 设计师"三方利益相关者拉到同一张桌子，目的不是"达成共识"，而是"**广泛听取两方用户对于关键问题的声音，发现痛点并探寻客观公正的价值权衡方法**"。

**证据**：
- LX5e_29 "车媒介@医疗设计共创工作坊"（NICE 公社 2021-02-28）官方原文：MeX 由刘胧教授指导的医疗共创设计研究项目；工作坊主题"未来服务型车载 CT 设备"；利益相关者明确写 = 影像医师 + 有 CT/MRI 经验的患者 + 医疗领域设计师
- LX3-03 *Exploring medical co-design in the AI era*：医疗设计师面临"high knowledge barriers + coordinating multiple interests"两大挑战，MCD 是 effective approach
- LX3-13 *AI-Augmented Co-Design in Healthcare* 实证：6 个四人团队 + 五阶段共创 + AI 助手日志 → "参与平衡 + 节奏清晰的团队产出更高质量"
- 教育部 2023+2024 连续两年立项"医疗人因设计创新与可用性工程联合实验室"

**应用场景**：
- 医疗器械产品设计
- 医院流程 / 诊疗服务设计
- 残障 / 老龄人群产品共创
- 任何"专业知识高 + 利益相关者多元"的议题

**局限**：
- 三方时间协调成本高——尤其是医生
- 患者群体对"被研究"的敏感性（医疗伦理审批必走）
- "客观公正的价值权衡"在产业落地时容易被甲方需求挤压

### 模型 3：4 种设计赋能方式（实操工具箱）

**一句话**：设计赋能不是抽象口号，是**4 个可操作的着力点**——动机赋能（激励）/ 关系赋能（连接）/ 人工物赋能（支持）/ 信息赋能（传达）。任何"赋能式"项目应能映射到这四个维度，**缺哪个补哪个**。

**证据**：
- LX3-10《积极老龄化视角下的设计赋能方式探究：基于"手段-目的链"的案例研究》（董玉妹 / 刘胧 / 董华）
- 方法论：Means-Ends Chain 多案例分析（6 个全球积极养老案例）
- 论文图 4 "四种设计赋能方式及其结构"作为该框架的官方可视化

**应用场景**：
- 积极老龄化产品 / 服务设计
- 健康行为干预设计
- 社会创新设计 / 公共服务设计
- 任何"赋能式而非替代式"的设计议题

**局限**：
- 仅在积极老龄化语境验证；扩展到儿童 / 残障需重新校准
- "人工物赋能"在数字 vs 实体产品的表现差异较大
- 与"通用设计 7 原则"未做正面对照

### 模型 4：信任校准实验（Trust × Error Bias × Transparency）

**一句话**：自动驾驶 / 人机协同的信任校准实验设计，应锁定 1-2 个**新变量**（不堆砌）+ 双轨方法（驾驶仿真器实验 + 大规模问卷）+ 国际联培节奏（CSC + 欧洲合作机构 1-2 年）。

**证据**：
- LX3-05/14/15/16/18 自动驾驶 5 篇连贯系列：每篇锁定 1-2 个新变量（trust × error bias / SAT level / perceived benefit / COVID context）
- LX3-14 由 LMU Andreas Butz 联署 + CSC 联培小李博士
- LX3-15 IATSS Research：429 份问卷大样本调研

**应用场景**：
- L3 自动驾驶 HMI 实验设计
- 任何"AI 助手 + 人监督"场景（医疗 AI / 编程 AI）
- 信任校准 / 接管时机研究
- 博士生培养 + 国际联培规划

**局限**：
- 主要在 L3 仿真器，L4/L5 真实道路样本不足
- "trust" 测量量表本身有争议
- 文化变量（中国 vs 欧美）的交互效应仍待补

## 决策启发式（7 条）

### 1. 方法论双轨：质性 + 量化

- **规则**：每个研究问题质性 + 量化双轨配套——SHEL（质性）+ 故障树概率树（量化）；scoping review + 实证；case study + MEC
- **来源**：LX3 全集"qualitative and quantitative methods" / "mixed-methods approach" 高频
- **应用场景**：选方法时强制问"另一轨我有没有"

### 2. 共创工作坊三件套：影像医师 + 患者 + 设计师

- **规则**：医疗共创工作坊**永远三方齐全**——影像医师 / 患者 / 设计师（或对应的医生 / 患者 / 设计师），缺一方就退化为"用户访谈 + 设计评审"
- **来源**：LX5e_29 MeX 工作坊官方表述
- **应用场景**：医疗类共创组织 / 校企合作工作坊

### 3. AI 助手在共创的位置：信息基广延 / trade-off 凸显 / concept checking

- **规则**：AI 在医疗共创中**不替代**任何人发言权，只做三件事——
  - 信息基广延（Information broadening）：扩展三方未涉及的相关信息
  - Trade-off 凸显：把价值权衡明确化
  - Concept checking：验证概念是否站得住
- **来源**：LX3-03 综述 + LX3-13 实证（AI 助手日志记录"谁在何时说话 + 工作进度"）
- **应用场景**：MeX 升级版工作坊 / AI co-design 实验

### 4. 实验变量"半步移动"

- **规则**：每篇实证论文锁定 1-2 个**新变量**——不要堆砌 5+ 个变量；trust × error bias 是一个移动，trust × transparency 是另一个，不混做
- **来源**：LX3-05/14/15/16/18 时间序列；每篇都"换一个变量推进"
- **应用场景**：博士开题 / 投稿论文设计

### 5. 国际联培"两年滚动"节奏

- **规则**：CSC 联培 1 年 + 国内合作 1 年 = 2 年滚动；这期间**至少产出**一篇与海外教授联署的论文（LX3-14 模式）
- **来源**：小李博士 CSC + LMU Butz 联培经历 + LX3-14 联署
- **应用场景**：博士生申请 CSC / 国际合作论文规划

### 6. 跨文化变量永不可省

- **规则**：医疗器械 / 包容性设计 / AV 接受度研究**必须**显式纳入跨文化变量——LX3-07 / LX3-15 / LX3-19
- **来源**：见 researcher.md 启发式 #6
- **应用场景**：国际期刊投稿 / 涉及 ≥2 国用户研究

### 7. 边际平等观的产业落地：先 4 种赋能，再资源差异化

- **规则**：把"边际平等观"落到产业，不要直接说"差异化资源"——先用"4 种赋能"工具化（动机/关系/人工物/信息），再在每个着力点上分人群差异化
- **来源**：LX3-09 → LX3-10 时间序列 + LX3-20 算法化延伸
- **应用场景**：包容性产品产业咨询 / 老龄化产品规划

## 方法论工具箱（核心方法 + 操作步骤）

### 工具 1：FMECA 全流程（医疗器械人因评估）

**操作步骤**：

1. **建立 SHEL 模型**——把系统分解为软件 / 硬件 / 环境 / 人四元；每元下列出可能的失效模式
2. **失效模式枚举**——基于产品使用流程，列出 50+ 候选失效模式
3. **三因子评分**——Occurrence（发生频度）/ Severity（严重度）/ Detection（可探测度），每个 1-10 分
4. **传统 RPN 计算**——RPN = O × S × D
5. **模糊化改造**（LX3-04 路径）：
   - 用模糊信念结构（fuzzy belief structure）替换离散评分
   - 用 FER（Fuzzy Evidential Reasoning）聚合多专家评估
   - 用 BRB（Belief Rule Base）建模因子非线性关系
   - 用 Dempster 组合规则汇总
6. **风险优先级排序 + 改进建议**

**适用案例**：
- LX3-04 远洋渔船
- LX3-06 C 臂 X 射线机
- LX3-02 多功能医用床

**局限**：模糊数学实施门槛高；产业落地时建议**先做传统 RPN 试点，再升级模糊版本**。

### 工具 2：MeX 共创工作坊脚本（6 节手册）

**Section 1：利益相关者地图**
- 列出三方代表：影像医师（≥2 名 / 不同年资）+ 患者（≥4 名 / 不同病程或经验）+ 设计师（≥3 名 / 含外部）
- 资金 / 伦理审批先走（IRB）

**Section 2：田野调查 + 信任建立（前 2 周）**
- 每位利益相关者做 60 分钟 1 对 1 访谈
- 建立"我们不是来卖产品的，我们是来听问题的"基调

**Section 3：工作坊流程（1 整天 / 5 阶段）**

| 阶段 | 时间 | 内容 |
|------|------|------|
| 阶段 1 - Warmup | 30min | 三方各自介绍 + 期待澄清 |
| 阶段 2 - 痛点挖掘 | 90min | 每方独立列痛点（卡片墙）+ 三方互相提问 |
| 阶段 3 - 价值权衡 | 90min | 把痛点按"医生价值 / 患者价值 / 设计师价值"映射 + 标注矛盾点 |
| 阶段 4 - 方案共创 | 120min | 4-5 人小组 × 3 组并行原型 + AI 助手 concept checking（如有） |
| 阶段 5 - 互评 + 收敛 | 60min | 三方互评 + 投票收敛 |

**Section 4：原型设计（工作坊后 2 周）**
- 把工作坊收敛的方向做出 paper prototype
- 回访三方做 cognitive walkthrough

**Section 5：交付清单**
- 利益相关者地图（A3）
- 痛点-价值矩阵（A2）
- 共创方案 3-5 个（PPT + paper prototype）
- 后续推进时间表（4-8 周里程碑）

**Section 6：后续闭环**
- 30 天后：三方各 1 名代表面访"方案演化情况"
- 90 天后：复盘工作坊本身的"参与平衡 + 节奏清晰"指标（参考 LX3-13）

**真实案例**：MeX × NICE 公社 × 听介传媒车载 CT 共创工作坊（2021-02-28）

### 工具 3：信任校准实验设计（自动驾驶 / 人机协同）

**核心要素**：

1. **变量锁定**：每个实验只动 1-2 个变量
   - LX3-05：error bias（false alarm vs miss）
   - LX3-14：reliability framing × error bias
   - LX3-18：transparency level（SAT 1 / 1+3 / 1+2+3）

2. **双轨方法**：
   - 驾驶仿真器实验（实验室控制）：参与者 30+ / 重复测量 / 双任务 / 接管时延
   - 大规模问卷调研（社会现场）：429+ 样本 / 跨地区 / 跨情境（COVID 前后）

3. **测量指标**：
   - Trust（信任量表 + 行为指标）
   - Situation awareness（SAGAT / SART）
   - Take-over time / quality
   - Perceived risk / Perceived benefit

4. **国际联培嵌套**：CSC 1 年 + 国内 1 年 = 2 年滚动；至少 1 篇与海外联署

**适用场景**：L3 自动驾驶 / AI 助手监督 / 任何信任 fragile 的人机协同

### 工具 4：MEC（Means-Ends Chain）多案例分析

**用法**（来自 LX3-10）：

1. **挑选 6+ 案例**——全球范围 + 跨文化 + 同议题
2. **每案例做"手段→目的"链推导**——把表层设计动作 → 中层用户价值 → 深层人生意义
3. **跨案例归纳**——找出共性结构（如 LX3-10 的"动机/关系/人工物/信息"四种赋能）
4. **图谱化**——画出 4 种方式的结构图

**适用场景**：
- 包容性 / 老龄化产品
- 社会创新案例研究
- 价值层级导向的设计研究

### 工具 5：scoping review + 实证双篇模式

**步骤**：

1. **第一篇：scoping review**——用 PRISMA-ScR 协议综述领域全貌（如 LX3-03 *Exploring medical co-design in the AI era*）
2. **第二篇：实证**——基于综述发现的最大 gap 做实证（如 LX3-13 AI 助手日志 + 团队节奏）
3. **博士培养中作为"双篇"模式**——一作综述 + 一作实证 = 一个完整 Story

**适用场景**：博士生培养 / 新兴领域开局 / 有 gap 但缺实证的议题
