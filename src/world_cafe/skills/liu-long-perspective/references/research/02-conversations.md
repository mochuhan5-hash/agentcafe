## A. 课堂结业致辞 / 教学场景的口头原话（最重要 ⭐⭐⭐⭐⭐）

### A1. 2022 年春《技术驱动，健康未来》课程结题致辞（来源 S36 = LX5e_24）

> 来源：LX5_extra/LX5e_24《课程成果丨2020级工业设计：技术驱动，健康未来》（同济 D&I 公众号）。该文末"教师结语"栏目，6 位指导教师按出场顺序留下原话。**刘胧老师列在第一位**，发言全文如下（原文照录，未删节）：

```
刘胧老师：
首先需要表达对各位老师的感谢。老师们给了同学们很多支持，
我代表同学们感谢所有参与课程的老师。
然后也希望同学们可以感谢一下自己。
这学期遇到了很多不可抗力因素的影响，
今天结题能够达成这样一个成果很不容易，结果很圆满。
在二年级这个阶段尽管产出还有一些不足，
但我们确实看到了每一位同学的进步，
这次的课题也让大家对未来设计有了更多的认识，
也希望大家继续保持对设计的热爱，继续努力！
```

**字数统计**：原文 8 句话，约 145 字。**这是当前已确认的本人口头语料的最完整样本**。

#### 句式 / 修辞观察

| 句式特征 | 实例 | 频次 |
|---|---|---|
| **代表性表达**（"代表 X 感谢 Y"） | "我代表同学们感谢所有参与课程的老师" | 1 |
| **辩证 / 让步式**（先承认不足，再肯定进步） | "尽管产出还有一些不足，但我们确实看到了每一位同学的进步" | 1 |
| **温和递进式鼓励**（"继续 X，继续 Y"） | "希望大家继续保持对设计的热爱，继续努力" | 1 |
| **第一人称复数**（"我们 / 大家"——拉近老师与学生的距离） | "我们确实看到了"、"大家继续" | 高频 |
| **基底情绪：理性肯定 + 温和鼓励**（不煽情、不夸张） | 整段 | 整体基调 |

#### 此致辞反映的"教师哲学三连发"
1. **先感谢校外/合作老师，把功劳分给团队** —— "我代表同学们感谢所有参与课程的老师"
2. **承认困难情境，但用"圆满"二字定调** —— "今天结题能够达成这样一个成果很不容易，结果很圆满"
3. **承认阶段性局限，但聚焦于"进步"** —— "尽管…还有不足，但…看到每一位同学的进步"

> 这与 LX1 草稿中那 5 条对仗工整的"经典语录"形成强烈反差：刘胧本人的真实致辞语气**朴素、口语化、温和、有具体所指**，不是格言体。

### A2. 学生引述的"口头禅"（来源 S37 = LX5e_41，2018 届毕展专访 麻珮琦同学讲述）

> 原文出处：LX5_extra/LX5e_41《【你好，毕展】都是产品设计，但我们不一样》→ 麻珮琦（指导教师：刘胧）回答"在毕业设计的过程中碰到的让自己印象最深刻的是什么？"

```
印象最深的是，在造型阶段，和刘胧老师因为气雾剂上的一根曲线而争论不休吧哈哈哈。
导师的要求很高，每次汇报完进度，回复我的总是"比之前好，但还不够好。"
（但也真的谢谢老师！我学到了特别多！）
```

#### 双口头禅 ⭐⭐⭐
1. **"比之前好，但还不够好"** ← **每次汇报反馈的标志性回应**（学生原话："每次汇报完进度，回复我的总是…"）
2. **"和老师因为气雾剂上的一根曲线而争论不休"** ← 评图细节抠到曲线级别的工作风格

#### 这两个口癖反映的指导风格
- 既肯定（"比之前好"）又持续推动（"但还不够好"），**对学生形成"持续小步迭代"的反馈节奏**，而不是"通过/不通过"的二元判定
- 评图细致到"一根曲线"，反映"工程理性 + 工业设计造型把关"双重标准
- 学生评价反差："导师的要求很高" + "（但也真的谢谢老师！我学到了特别多！）" = **典型的"严师 + 学生最终感激"** 的关系结构

**字数**：原文 138 字（不含署名）。

#### 用语指纹（中国高校学术型推荐信的典型范式）
- 高频成对短语：**"认真踏实 / 刻苦努力" / "长足的进步" / "严格要求自己" / "突出的贡献" / "取得更大的成绩"** —— 全部是**中国高校学术推荐信传统词典**中的"标准词"
- 句式：四字一组、并列、工整 —— 与课堂口头致辞 (A1) 的口语化形成鲜明对比
- 显然遵循中国高校"导师推荐信书面体"的规范，没有个性化的隐喻或文学表达
- **可与 LX1 那 5 条"经典语录"对比**：LX1 的措辞（"设计的责任，不仅是创造体验，更是识别并规避风险"）= LLM 合成的格言体；本段 = 真实书面体 = 朴素的高校推荐信范式。**两者文风完全不重合**，证明 LX1 不是本人作品。

## F. **不构成本人语料** 的素材警示（必读）

### F1. LX1 的 5 条"经典语录"——LLM 合成嫌疑 ⛔

> LX1（个人介绍）末尾出现 5 条对仗工整的"经典语录"：

```
1. "设计的责任，不仅是创造体验，更是识别并规避风险。"
2. "没有用户行为数据的设计，只是猜测。"
3. "包容性不是附加项，而是设计本质的一部分。"
4. "工程思维让设计变得可靠而有意义。"
5. "人机系统的优化，不仅提升效率，更守护生命与健康。"
```

**判定**：⚠️ **本团队明确不采信这 5 条作为本人语录**，理由：
1. 句式高度对仗工整（"不仅…更是…"、"…只是…"、"…的…部分"）—— 不符合 A1（课堂致辞）和 B1（推荐信）中刘胧本人书面/口头表达的风格指纹。
2. LX1 整页存在大量 `￼` 占位符，并使用 `<经典语录>` 这种 prompt-template 风格的标签，强烈疑似 LLM 草稿。
3. 5 条语录在公开渠道（S1-S25 + LX5）的真实文字中**完全没有同源对应**——任何一条都找不到对应的访谈、会议或文章原文。

→ **以下文件均同步标注此警示**：03-expression-dna.md（顶部 banner）。
