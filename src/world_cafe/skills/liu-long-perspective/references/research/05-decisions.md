# 05 领域背景与决策节点（刘胧）

> 本文件按"四大支柱领域"展开：①医疗器械人因/医疗共创、②包容性设计/多样性/老龄化、③交通系统人因（自动驾驶/飞梭智行）、④太空设计/在轨建造。每个领域含 4 段：背景 → 切入点 → 核心判断 → 决策逻辑。文末附**重要决策节点时间表**（1989–2026）。

---

## 支柱一 · 医疗器械人因 / 医疗共创（最早 / 最深 / 跨度 20 年）

### 1.1 背景
- 2003 年中国实施 ISO 14971 医疗器械风险管理标准；2004 年欧盟 EN 60601-1-6 把"医疗器械可用性工程"写进强制要求 → 全球医疗器械人因领域的法规化窗口期。
- 关键统计支撑（LX3-02 引用）：1999 年美国 IOM 报告《To Err Is Human》估算"美国每年有多达 98,000 的住院病人由于可避免的医疗错误而死亡"；FDA 1991 年研究"1984-1991 年约 130,000 项医疗事故中 60% 与使用者操作错误有关"。

### 1.2 切入点
- **从核工业的 HRA 传统借用方法学**（SHEL / 故障树 / CREAM 第二代 HRA），把核工业成熟的"可靠性 + 失效模式"工具引入中国医疗器械人因（LX3-02/04/06/12）。
- **跨文化变量**：与 Hoelscher 联合论证 "medical device cross-cultural design"（LX3-07 + Handbook 章节 LX3-19）。
- **方法演化**：SHEL/FMECA → 模糊数学/灰色关联（LX3-04/12）→ 共创设计（MCD）→ 共创+AI（LX3-03/13）。

### 1.3 核心判断
- **"由设备技术因素引发的使用风险逐渐下降；由设备操作人员行为不安全性引发的事件或事故逐年上升"**（LX3-02 引言原文）→ **必须由"设备可靠性"转向"人的可靠性 + 设备-人-环境-软件四元交互"**。
- **"对医疗领域中，人的失误是一个致命的因素"**（LX3-02）。
- **"medical designers face the challenges of overcoming high knowledge barriers and coordinating multiple interests. MCD is regarded as an effective approach to addressing these challenges"**（LX3-03 摘要原文）。
- **教学指导原话（间接转述）**："**由改善体验深入到帮助患者进行复健**"（LX5_04 With U）—— 凡医疗设计，都要从"用户体验问题"升级到"医疗康复 outcome"。

### 1.4 决策逻辑
1. **方法选型**：优先选可靠性工程（FMEA/FMECA/CREAM）类工具，但**质性 + 量化双轨并用**。
2. **跨文化扩展**：风险评估边界一定跨文化（LX3-07/19）—— 是其德国博士培养经历的内化判断。
3. **共创组织**：超过单方专业能解决的问题（医疗共创）→ **必须把患者-医生-设计师三方拉进同一个工作坊**，"广泛听取两方用户对于关键问题的声音，发现痛点并探寻**客观公正的价值权衡方法**"（LX5e_29 工作坊原话）。
4. **AI 工具的位置**：把 AI 作为"信息基广延 + trade-off 凸显 + concept checking"的设计共创助手（LX3-03 / 13）。
5. **产业化对接**：选择"专精特新"中型医疗器械企业（丰凯利）+ 医疗影像龙头（联影）+ 国家级"人因与工效学"产学合作平台（津发）三类合作渠道。

## 支柱二 · 包容性设计 / 多样性设计 / 积极老龄化

### 2.1 背景
- 老龄化加速：UN《世界人口展望 2019》60+ 全球人口将从 2019 年 10 亿 → 2030 年 14 亿（占总人口 16.4%）。
- 中国设计学界在 2010-2020 间从"通用设计（Universal Design）"语境转向"包容性设计（Inclusive Design）"的话语主流化。
- 同济 D&I 包容性设计研究中心 = 中国包容性设计的代表性平台之一（与 Hua Dong 合建）。
- 设计赋能（Empowerment）作为参与式设计 + 社会创新设计核心概念，但**"设计结果如何赋能于人的具体方式缺乏研究"**（LX3-10 引言）。

### 2.2 切入点
- **理论原创：边际平等观（Marginal Equality）**（LX3-09 黎昉/赵阳/刘胧）：批判普世平等观在通用设计/包容性设计实践中的局限，提出"基于边际差异的边际平等观"。
- **方法论原创：4 种设计赋能方式**（LX3-10 董玉妹/刘胧/董华）：基于 6 个全球积极养老案例 + Means-Ends Chain，归纳"动机/关系/人工物/信息"赋能 → 对应"激励/连接/支持/传达"4 个设计着力点。
- **AI 化扩展**：LX3-20 *Using AI to Enable Design for Diversity* —— "diversity-oriented design will tend to allocate design resources and values in an algorithmic way rather than the compromised unity solution"。

### 2.3 核心判断
- **"对设计平等、公正和包容的价值诉求与用户固有的多样性差异之间存在矛盾"**（LX3-09 摘要）—— 包容性设计领域最根本的"问题陈述"。
- **"普世平等观把所有人当作一样的人去服务；边际平等观承认差异客观存在，对边际人群施以差异化设计资源"** —— 概念辨析的标志性陈述。
- **"将被帮助对象视作'问题解决的能动者'，将实务工作者视为具有可用知识和技巧的协作者"** —— 赋能视角的核心立场。

### 2.4 决策逻辑
1. **概念创新优先于工具创新**：先提出新的概念框架（边际平等 / 4 种赋能），再让具体工具落地。
2. **国际合作锚定**：核心理论合作伙伴 = Hua Dong（Brunel/Loughborough）。
3. **设计赋能的 4 个着力点 = 一个可被产业落地的工具箱**（动机/关系/人工物/信息）。
4. **公共卫生延展**：LX3-08（Frontiers in Public Health）孤独 × 高血压研究 → 边界从"产品-用户"扩展到"健康-生活方式-社区"。
5. **不与"通用设计"全面对立**：承认普世平等观的"作用与局限"，是渐进改革派。

## 支柱三 · 交通系统人因（自动驾驶 / 人机信任 / 飞梭智行）

### 3.1 背景
- 2010s 后期 Level 2-3 自动驾驶系统（ADS）进入消费级；信任校准 / HMI 透明度 / 人机协同成为人因热点。
- LX3-15 数据：2023 年中国调研中，"the average extra cost willing to pay for a fully AV was 28,855.88 CNY (4116.39 USD), and 26.8% of resp[ondents] …"。
- 中国设计学界对自动驾驶的研究多偏 HMI 视觉/服务设计；人因层面的"信任 × 错误偏置 × 透明度"实证较稀缺。

### 3.2 切入点
- **以人机信任为核心变量**：5 篇连续论文（LX3-05/14/15/16/18）锁定 trust → driving performance → take-over → reliance 链。
- **错误偏置（error bias）作为新解释变量**：把信任研究里的"reliability"二维扩展为"reliability × error type（false alarm / miss）"+ perceptual salience。
- **透明度分级实验**：把 SAT（Situation Awareness-based Transparency）三级在驾驶仿真器上做参与式实验（LX3-18）。
- **博士生主力**：小李博士（Jue Li）= 主线作者；汪小姗（Xiaoshan Wang）共作。
- **国际合作**：CSC 联培 → 慕尼黑 LMU Andreas Butz（LX3-14）。
- **产业方向**：江苏飞梭智行（LX4-01 轨道车辆专利合作方）。

### 3.3 核心判断
- **"System reliability promotes trust, but may also impair human monitoring performance and in turn affects trust. This effect varies across different errors."**（LX3-14 摘要）。
- **"漏报对信任的损害比误报更大"**（LX3-05/14 一致结论），违反传统的"漏报更好"直觉。
- **"transparency 不是越透明越好"**（LX3-18）：SAT level 1+3 / 1+2+3 比 baseline 都好，但边际效用未必成正比。
- **"AV 接受度受文化 / 疫情情境影响"**（LX3-15 COVID-19）—— 反对一般化结论。

### 3.4 决策逻辑
1. **以变量为单位推进**：每篇论文锁定 1-2 个新变量，不堆砌系统综述。
2. **方法论双轨**：参与式驾驶仿真实验（实验室）+ 大规模问卷调研（社会现场）。
3. **国际联培是博士生培养标配**：CSC + LMU 双方资源把博士生送到欧洲合作机构 1-2 年。
4. **学生一作 + 导师通讯**：博士培养产出 + 团队整体影响力的稳定平衡。
5. **不押注 L4/L5**：选择 Level 3 作为研究焦点，因为 L3 才是"信任校准 + 接管"问题最尖锐的层级。

## 支柱四 · 太空设计 / 在轨建造（v3 起新发现）

### 4.1 背景
- 2020s 中后期太空商业化（SpaceX / 蓝色起源 / 中国空间站 / 月球探测）激活；中国"探月探火空间站"国家战略推动太空 × 设计学的交叉。
- WDCC 2024 同济 D&I 学院展（孙捷策展）把"宇航与交通工具创新"列为四大方向之一（S38 = LX5e_33）。
- 同济 D&I 内部出现"近未来太空家园 / 在轨建造"的研究/教学方向。

### 4.2 切入点
- **WDCC 2024 参展作品《太空家园》**：刘胧团队 **11 人**（樊中、王心怡、顾丽雯、吕晶、尹硕、黄佳捷、滕雪苗、吴淑婷、任雅馨、杨丽尼 + 刘胧）。
- **教学先行**：2024 春《星辰大海 Stars in Wide Sky》2022 级工业设计课题（LX5e_22）—— 刘胧 + 樊中 + 陈佶璐 + 单荃，10 个学生组，主题"地月之间 / SpaceX / 以人为本的未来生活"，覆盖月面食物培育（DeMoonter）、月球深空接驳（Farjan）、氦-3 采能、月球外骨骼（Moon Trekker）、3D 打印月球建造（月堑重构）等。
- **专利铺垫**：LX4-01 江苏飞梭智行轨道车辆专利（2024）虽然是地面交通方向，但**学生发明人尹硕、黄佳捷、顾丽雯**与太空团队部分重叠 —— 表明团队跨界（地面交通 ↔ 太空交通）共用人才。

### 4.3 核心判断
- 教学课题描述原文（推断为他作为课程负责人的判断输出）：**"本课题旨在探究宏大宇宙场景下人类的活动及其场景、工具的可能形式"** + **"以人类未来生存发展为目标，挖掘在未来场景中人类太空探索可能面临的挑战和机会"**（LX5e_22）。
- 关键词："**人、空间、产品、智能复杂系统**"+"**以人为本的未来生活**"+"**想象力和创造力**"（LX5e_22 课题关键词）—— **把"以人为本"从医疗 / 包容性 / 交通三大场景延展到太空场景**，保持核心方法论不变。

### 4.4 决策逻辑
1. **教学先行 / 论文跟进**：课程 + 展览 + 学生项目先打基础，**学术论文（SCI/EI）尚未出现**——这是设计学典型的"实践→反思→学术化"节奏。
2. **从地面交通自然延伸**：江苏飞梭轨道车辆 → 月面交通 → 太空家园，**"交通-人居-生存"三位一体**的研究脉络。
3. **跨方向师资集合**：樊中（产品 / 制造）+ 陈佶璐（实验 / 体验）+ 单荃（教学）+ 顾丽雯（核心助教）= **典型的 ErgoDe + 邻接老师跨组合作**。
4. **延续"客观公正的价值权衡方法"工作坊范式**：把医疗共创工作坊的方法迁移到太空场景。

## 冲突与盲区
